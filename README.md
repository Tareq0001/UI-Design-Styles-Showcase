# 🎨 Archetype UI Studio — استوديو أنماط التصميم البصري

> **منصة تفاعلية حية تستعرض 12 فلسفة وتوجهاً جذرياً في تصميم واجهات المستخدم والويب مع محاكاة فيزيائية وتشريح هندسي فوري.**

---

## 🌟 نظرة عامة (Overview)

تم بناء هذا الاستوديو لكسر رتابة القوالب البرمجية المتكررة وتقديم تجربة بصرية وتفاعلية حية تثبت كيف يتغير المعنى، الإحساس، والهوية التفاعلية للمنتج الرقمي ذاته بمجرد تغيير الفلسفة المعمارية للتصميم.

---

## 🏛️ الأنماط المعمارية الـ 12 المشمولة (The 12 Archetypes)

1. **🏔️ النمط العسيري المعماري (Neo-Asiri Geometric Heritage):**
   - مستوحى من قلاع وحصون السودة وعسير الحجرية، شرفات الجص البيضاء المفرغة، وحزام القط العسيري الأصيل بألوانه التراثية (القرمزي، الأخضر السروي، الأصفر الفاقع، والأزرق النيلي).
2. **📐 النمط السويسري الصارم (Swiss International Typographic):**
   - شبكة أعمدة 1px صلبة، تيبوغرافي عملاق عريض غير مذيل، تباين الأبيض والأسود المطلق مع البرتقالي الدولي، بدون بطاقات أو زوايا دائرية.
3. **⚡ النيو-بروتاليزم الحسي والمرح (Tactile Neo-Brutalism):**
   - حدود سوداء 3.5px، ظلال مسقطة صلبة ومفرغة بزاوية حادة 0-blur، ألوان نيون فاقعة، وشارات مائلة تنضغط فيزيائياً.
4. **📟 السايبربانك وشاشات HUD التكتيكية (Cyberpunk Tactical HUD):**
   - قمرة قيادة عسكرية مستقبلية، خطوط مسح CRT، زوايا مشطوفة 45 درجة، أرقام سداسية عشرية، وتوهج نيون مستمر.
5. **🌿 النمط النوردي الهادئ (Nordic Serene / Warm Minimal):**
   - فلسفة الهدوء والسكينة، ألوان خشب البتولا والميرمية، أشكال بيضاوية ناعمة، مساحات بيضاء شاسعة تتنفس براحة تامة.
6. **💎 الزجاج السائل والشفق القطبي (Liquid Glass & Aurora Mesh):**
   - ألواح زجاجية حقيقية بانكسار ضوئي كثيف (Backdrop blur 25px)، حدود متوهجة بلمعان مائل، وخلفية شفق قطبي نابضة بالحياة.
7. **🎛️ الريترو التجسيدي الكلاسيكي (Classic Aqua Skeuomorphism):**
   - أزرار جيلية لامعة ثلاثية الأبعاد (Aqua Pills)، أسطح معدنية مصقولة، إضاءة علوية وانعكاسات كبسولية واقعية ملموسة.
8. **🪐 جماليات Y2K والكروم الفضائي (Y2K Cyber Chrome & Gel):**
   - أسطح كروم معدنية سائلة عاكسة، نجوم لمعان فضائية رباعية (✦)، فقاعات هلامية، وحروف ممتدة أفقياً.
9. **🏛️ التحريري الصحفي الفاخر (Editorial Luxury / High-Fashion Serif):**
   - خط سيريف عريض كلاسيكي، تباين الأبيض العاجي والأسود الحبري والبرونز، خطوط أفقية شعرية، وأناقة أرستقراطية بالغة.
10. **🔘 النيومورفيزم الطيني المنحوت (Neumorphism / Soft Extruded Clay):**
    - عناصر منحوتة مباشرة في مادة السطح بدون حدود، بفضل ظلال ثنائية محسوبة بزاوية النور والظل.
11. **💻 الريترو تيرمينال وشاشات CRT الثمانينات (80s Monochrome CRT Terminal):**
    - إشعاع الفوسفور الأخضر المتوهج، خطوط نقطية Monospace، إطارات ASCII، وميض المؤشر الميكانيكي.
12. **🌱 البيوفيلي الطبيعي والتقنية العضوية (Biophilic Organic Nature-Tech):**
    - زوايا عضوية غير متناظرة (Organic Blobs)، ألوان الغابات والمستنقعات النظيفة، وملمس ترابي هادئ ومستدام.

## 🛠️ المزايا التفاعلية في الاستوديو

- **المسرح التفاعلي الحي (Live Stage Canvas):** تبديل فوري لكامل بيئة العرض، الخطوط، والفيزياء.
- **3 سيناريوهات حية متطابقة:**
  1. 🛒 بطاقة منتج تفاعلية (E-Commerce Card)
  2. ⚡ لوحة تحكم SaaS مع مقاييس حية (SaaS Action Console)
  3. 🎵 مشغل وسائط مع متخيل موجات صوتية نابض (Haptic Media Player)
- **معمل العناصر الدقيقة (Micro-Components Lab):** تجربة الأزرار، حقول الإدخال، المفاتيح، والشرائح.
- **مقارنة نمطين جنباً إلى جنب (Split Compare Mode):** لمشاهدة الفروق الجوهرية بين نمطين متناقضين وجهاً لوجه.
- **التشريح الهندسي (Inspector):** لوحة ألوان قابلة للنسخ بنقرة واحدة، قواعد الاستخدام، وكود الـ CSS الصافي للنمط.
- **تأثيرات صوتية فيزيائية (Tactile SFX):** استجابة نقر صوتية دقيقة وممتعة عبر Web Audio API.
- **دعم ثنائي اللغة كامل:** العربية والإنجليزية.
